## 📘 About

This repository contains my work for **[CS50’s Introduction to Artificial Intelligence with Python](https://cs50.harvard.edu/ai/)**. Each folder holds a project solution with clean, commented code and short notes on what I learned.

---

## 🧠 Topics Covered

- **Search** — BFS, DFS, A*, minimax, alpha-beta pruning
- **Knowledge** — propositional logic, inference, constraint satisfaction
- **Uncertainty** — Bayesian networks, probabilistic reasoning
- **Machine Learning** — regression, gradient descent, decision trees
- **Neural Networks** — perceptrons, backpropagation, deep learning
- **Reinforcement Learning** — Q-learning, Markov decision processes
